# prompts/ —— 本地覆盖目录

## 这里**故意没有**提示词模板的副本

提示词（版式段 / 英文标准段 / 负面词 / 文字屏蔽段）**全部在运行时从工作流读取**：

| 内容 | 权威来源 |
|---|---|
| 三视图版式英文段 · 一致性段 | `02-服化道/引擎/TURNAROUND-STANDARD.md` §1.3 |
| 服装 / 道具英文标准段 | 同上 §2.3 / §3.3 |
| 负面词（通用 + 三视图 + 按模块 + FAILURE 修复映射） | `02-服化道/引擎/NEGATIVE-PROMPT-LIBRARY.md` |
| 文字屏蔽强制段（含权重 `any text:1.8`） | `02-服化道/引擎/TURNAROUND-STANDARD.md` §1.6 |
| 质量参数 · 电影感具体化段 | 同上 §六 |
| 服装 25 字段 / 道具字段清单 | 同上 §2.1 / §3.1 |

**为什么不在本目录放副本**：副本必然与原文发散（工作流质量守则 §2「单一权威来源」）。
改规则请改工作流，本 Agent 下次运行即生效（live 模式）。

**查看实际加载了什么**：

```bash
python main.py rules
```

---

## overrides/ 的用途

`overrides/` 留给**本机专属微调**（不打算回灌工作流的内容），例如：

- 某个客户要求的额外禁止项
- 特定模型的参数偏好
- 临时试验的版式变体

文件命名约定：`<type>.<片段名>.md`（如 `character.layout.md` / `negative.extra.md`）。

> ⚠️ 覆盖机制**当前尚未实现**（V1.0 只读工作流）。若需要，
> 实现位置在 `src/prompt_engine.py` 的各 `build_*` 函数载入前插入一层覆盖查找。
