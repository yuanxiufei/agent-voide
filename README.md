# agent-voide

> AI 漫剧生产的**智能体提示词工程**项目 —— 一句话创意 → 可发布单集。

---

## 🎬 这是什么

一套**可部署、可自检**的 AI 漫剧生产智能体。把「写剧本 → 做资产 → 拆分镜 → 出视频 → 配音乐 → 过审」六个环节，做成六份可独立部署的智能体规格 + 可执行的规则引擎。

**核心定位**：agent 负责「**想清楚 + 写准提示词**」，人负责「**确认方向 + 按按钮生成**」。

## ✨ 特点

| 特点 | 说明 |
|---|---|
| **六模块可独立部署** | 每个模块的主控都能单独挂进 GPTs / Coze / Dify 使用 |
| **单一权威来源** | 同一知识只在一个文件维护，分三层（规格 → 引擎 → 模板） |
| **可自检** | `python 工具/校验.py` 一次跑 7 类检查（引用断链 / 改主控忘改模板 / 前缀残留 / 口径漂移 / 素材误删 / 文本损坏…） |
| **实跑验证过** | 六个模块均经过真实链路演练，曾用演练暴露并修复跨模块机制缺口 |
